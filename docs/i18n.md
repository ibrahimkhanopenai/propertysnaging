# Internationalisation (EN / AR)

- Locales: `en` (default, **no URL prefix**), `ar` (`/ar/`, `dir="rtl"`). Config: `src/i18n/config.ts`.
- `localePath(locale, "/about-us/")` → `/about-us/` or `/ar/about-us/`. Always use it for internal links.
- UI + homepage copy: `src/i18n/dictionaries/en.ts` and `ar.ts`. `ar.ts` is typed as `Dictionary`, so a missing key fails the build.
- Page copy: `src/content/pages.en.ts` / `pages.ar.ts`.
- Blog posts have a `locale` field; Arabic posts live at `/ar/{slug}/`. Posts don't have automatic translations, so blog posts are emitted without hreflang alternates.
- hreflang `en`, `ar`, `x-default` are added to every static page through `buildMetadata()` and to the sitemap.
- RTL: use logical Tailwind utilities (`ms-*`, `me-*`, `ps-*`, `start-*`, `text-start`). Directional icons: `rtl:rotate-180`. Phone numbers: wrap in `dir="ltr"`.
- **Arabic copy is a first draft — get it reviewed by a native speaker before launch** (tracked in `assumptions-and-todo.md`).
